What the numbers rest on

  • $0.28 a name — PDL, in the code as PDL_RATE_USD, confirmed on their dashboard. Pool-first sourcing serves anyone we already own free, so this is the worst case and it falls as the pool grows.
  • $0.07 to work a lead — REVEAL_MARGINAL_COST_USD $0.01 + WORK_MARGINAL_COST_USD $0.06.
  • $99 = 100 approvals included, then $4 each, no expiry. Founder-locked 25 Jul.
  • 200 names sourced up front so they have something to pass on. The sourcing fence caps a client at 100 names a day, so half arrives on payment day and half overnight.
  • The floor above is the honest one — and on 3 Aug it was wrong by $87/mo in ONE line. "Servers + database" read $138 and was tagged verified. The founder opened the actual bills: Railway $15.59 + Supabase $35 = $50.59. Nothing had changed at the vendors — the number was never checked against an invoice, and the "verified" tag made it un-rechecked by everyone who read it afterwards. A confident label on an unread number is worse than no number. Earlier versions carried $190 and left out Smartlead, Instantly and Zoho entirely.
  • 3 Aug — THE COST-PRESSURE CUTS (founder: "i cant afford 470/month… without income coming in this is impossible to maintain"). The response was not to cut the launch — it was to cut everything that was not the launch. Resend Pro → free ($20) · Apollo → free plan from 3 Sep ($65, with 2,500 already-paid credits usable through August) · Claude Code downgraded (~$130, current plan runs to 20 Aug) · and the $138 servers line corrected to $51 (−$87, an error not a cut). Nothing on the sending path was touched — Google Workspace, Instantly Growth and the domains all stayed, because cutting those saves ~$65 and moves first revenue further away, which is the actual problem. ~$470 → ~$157/mo all-in.
  • 30 Jul — CLIENT ZERO RUNS ON OUR OWN ENGINE (founder decision, amending his own 26-Jul #577 lock). Walked point by point: of Instantly's bundle we lack exactly one thing — the warmup network. The sequencer, sender and unibox duplicate the product we built and are trying to prove, and the $97 HyperGrowth tier was needed only for the API to integrate with a sender we no longer use. So Instantly drops to Growth $37, warmup only, and our engine does the sending. ⚠️ This makes the mailbox purchase specific, not optional: Google DIRECT (~$6/box), never Instantly's DFY boxes — #577 records in writing that vendor-provisioned mailboxes expose no SMTP credentials, and our send path requires them. The fuel, separate from the rent: ~$130–145 per 1,000 prospects (Apollo $65 actual, corrected 3 Aug from ~$49–59 + ~$8 verification + ~$70 AI writing) ≈ one client at conservative reply rates, burned over ~6 weeks at 4 warm boxes — and August's fuel is already paid: 2,500 Apollo credits sit unused before the plan drops to free on 3 Sep. One client is worth $99 + ~$121/mo — the acquisition maths works even at 1-in-1,000.
  • 30 Jul — IDLE TOOLS BILL NOTHING (founder rule). This is self-funded, so the defaults above are what is actually being spent right now, not what the model spends at client scale. A tool that is not doing work this month is set to $0 and carries the trigger that switches it back on: Hunter and PDL the month a sourcing run happens · Smartlead the day a client signs · the failover when there are clients to feel an outage. Floor $423 → $283.
  • 🪦 SUPERSEDED SAME DAY — "INSTANTLY-FIRST, HyperGrowth $97" (30 Jul, morning). This list briefly carried both this decision and the Client Zero lock above, which contradict each other — HyperGrowth's API existed to let Instantly send, and the Client Zero walk (30 Jul, later the same day) established our own engine sends, so the API tier buys nothing.
