# 🎬 K.I.N.D — Recording Playbook (script + motion-by-motion, by screen)

**Use the demo account, not a real client** (`/demo-login`) so the data is safe to show. Record on the **portal live URL** (`app.get-kind.com`).
**Brand voice:** authentic, no hype, "real run-through." Africa-first. *Augment, not replace* — "give every rep their own AI." Outcome-first: **1 credit = 1 positive reply.** Never say "revolutionary/game-changer."

## ✅ Pre-flight (every recording)
- [ ] Resolution: **16:9 → 1920×1080**; **9:16 → 1080×1920** (phone or a 9:16 browser window).
- [ ] Browser: full-screen, hide bookmarks bar + extensions, clean profile, cursor visible.
- [ ] Logged into the **demo account**; data looks healthy (leads scored, a campaign with replies).
- [ ] Close Slack/email. Do-not-disturb on. One take per scene; pause between scenes.
- [ ] Talking-head intro = optional (your call — haircut permitting 😄). Voiceover-over-screen works without face.
