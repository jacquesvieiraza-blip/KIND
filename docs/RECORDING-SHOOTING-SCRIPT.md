# 🎬 K.I.N.D — Scene-by-Scene Shooting Script (record one scene at a time)

**How to use this:** record **one scene at a time** in Screen Studio. Save each clip as its **scene number** (e.g. `1.3.mov`). The **SAY** line is your exact voiceover — read it into Loom/Descript (or live). Assemble scenes in order at the end. Pause Screen Studio's auto-zoom onto the thing the SAY line mentions.

**Before every session:** demo account (`/demo-login`) · notifications OFF · hide bookmarks/extensions · browser zoom **125–150%** · large cursor · quiet room.
**Voice:** calm, real, no hype. Let the screen breathe — the scripts are deliberately short.

> **🛠️ Tools & quality (the stack):** **Screen Studio** to record (auto-zoom + smooth cursor = premium-looking SaaS demos) · **Descript** for voiceover + "Studio Sound" cleanup · **CapCut** for 9:16 reframe + auto-captions. **Audio is the biggest quality lever** — a USB mic (Samson Q2U / Blue Yeti) or wired earbuds in a quiet, soft room beats the laptop mic; clean it with Descript Studio Sound. Export **1080p**, 30–60fps.
> _This is the **one** recording doc — it replaces the old `RECORDING-PLAYBOOK.md`._

## 🎚️ Per-scene Screen Studio tips
- Let **auto-zoom** land on the exact element each SAY line names (the score, the Step-1 opener, the reply).
- Record each scene with **2 seconds of stillness** at the start/end — gives clean cut points.
- If a live action lags, **pre-load the screen** and just record the reveal.
- Keep the cursor **slow and deliberate** — fast mouse movement reads as nervous.
