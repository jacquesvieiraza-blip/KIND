Approved leads get a POPIA consent email automatically, not when someone clicks a button. Consent → automatic status update via webhook. No manual "mark as consented" except as a fallback. Client sees it happen in the activity feed in real time.

**4. FIGSY campaign (one button, not a wizard)**
Once there are consented leads, the dashboard nudges: "You have 12 consented leads — start a FIGSY campaign." Client names it, clicks Generate. **6. Dashboard (a single scoreboard)**
Leads sourced → consented → emailed → replied → meetings booked. Live numbers, no refresh needed. Activity feed shows the last 20 events across all campaigns. Client knows at a glance if the machine is running.

**The gap between current and ideal:** steps 3 (auto-consent) and 6 (live numbers) are the two biggest friction points right now. Everything else is close.
