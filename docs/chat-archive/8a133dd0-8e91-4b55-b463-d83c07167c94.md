# 1. LEMLIST

**What they are:** The gold standard for multichannel cold outreach. Best-in-class personalisation, deliverability, and LinkedIn automation. 450M+ contact database bundled on higher tiers.

---

### Feature Map

**Sequences & Outreach**
- Multi-step multichannel: email → LinkedIn profile view → connection request → LinkedIn message → WhatsApp → call reminder — all in one sequence
- Conditional branching: if no reply after step 3, go to path B
- AI-generated full sequences from a campaign goal + value prop
- Multi-model AI: Claude, GPT, Perplexity — user picks per campaign
- A/B testing across subject lines, body copy, CTAs

**Personalisation (their superpower)**
- Dynamic text tokens (name, company, role, custom vars)
- Personalised images — prospect's name on a whiteboard, company logo on a screen, custom mockups — per recipient at scale
- Personalised video thumbnails — individual video links per prospect
- Landing pages that show prospect-specific content
- Image personalisation lifts open rates 5–15% vs text-only

**Deliverability**
- Lemwarm built-in (email warmup — exchanges emails with other warmed inboxes)
- Included from Email Pro ($79/month) upwards
- Deliverability dashboard — spam rate, inbox placement, sender score per mailbox

**Lead Database**
- 450M+ contacts (bundled on Multichannel Expert+)
- Email + phone + LinkedIn data
- Waterfall email verification built in
- No separate Apollo subscription needed on top tiers

**Integrations**
- HubSpot + Salesforce native 2-way sync
- Zapier, Make
- MCP server (launched 2025 — lets AI tools call Lemlist directly)
- Full API

**Client Portal / User-facing**
- No dedicated client portal — it's a tool you use yourself
- Unified inbox — all replies from all campaigns in one view
- Reporting dashboard: open rate, reply rate, bounce rate, click rate per campaign

**Admin / Agency Features**
- Multi-sender: 3–15 sending email accounts per plan
- Agency workspace: manage multiple client accounts under one login
- Team inbox with assignment routing
- Role management: Admin, Manager, User

**Pricing**
- Email Starter: $39/user/month
- Email Pro: $79/user/month (3 senders + Lemwarm)
- Multichannel Expert: $99/user/month (5 senders + LinkedIn + 450M DB)
- Outreach Scale: $159/user/month (15 senders)
- Enterprise: custom (min 5 seats)

---

### Where K.I.N.D Beats Lemlist

| K.I.N.D advantage | Why it matters |
|---|---|
| **Done-for-you** | Lemlist is a tool — client runs it themselves. K.I.N.D runs it for the client. |
| **Zero learning curve for client** | Lemlist requires training, setup, LinkedIn automation config, DNS setup. Our clients never touch any of it. |
| **Credit model (pay per lead)** | Lemlist charges per seat per month regardless of results. We charge for leads delivered. |
| **White-label client portal** | Lemlist has no client-facing portal. We do. |
| **African market + POPIA** | Lemlist has no African focus, no ZAR pricing. |
| **Dedicated client success** | Lemlist is pure self-serve. We are managed. |

### What to Steal from Lemlist

| Feature | How |
|---|---|
| **Personalised images** | Per-lead image generation with their name/logo — massive open rate lift. Art of Possible candidate. |
| **Multi-model AI toggle** | Let campaigns switch Claude vs GPT per sequence. Already parked. |

# 2. CLAY

**What they are:** The infrastructure layer for modern outbound. Not a sending tool — a data and workflow engine. Clay sits *before* Lemlist/Instantly/FIGSY in the stack. You enrich in Clay, then push to a sender.

---

### Feature Map

**Core: Data Enrichment (Waterfall)**
- 150+ data providers connected (Apollo, Clearbit, People Data Labs, Hunter, ZoomInfo, LinkedIn, etc.)
- Waterfall logic: try Provider A → if no result → try B → try C
- 20–40% more coverage than any single provider alone
- 2-3 credits per single-provider lookup; 4-8 credits for 3-provider waterfall
- Enriches: email, phone, LinkedIn, job title, company, funding, tech stack, headcount, intent signals

**Claygent — AI Research Agent**
- Autonomous web browsing: reads websites, LinkedIn profiles, news articles, job boards
- Extracts insights that databases can't: "does this company use HubSpot?", "what pain is this CFO talking about on LinkedIn?"
- Navigator: behaves like a real browser user — can interact with pages, fill forms, scrape niche directories
- Used for hyper-personalisation at scale: "write one sentence about their latest product update"

**Sculptor — Workflow Builder**
- Natural language: "build my outbound engine" → Clay builds the table/workflow
- Visual GTM workflow builder
- Connects enrichment → AI research → personalisation → push to CRM or sending tool

**Intent Signals**
- Job change alerts (prospect changed jobs = trigger sequence)
- Website visitor tracking (company visited your site = trigger)
- LinkedIn activity monitoring
- Funding rounds, hiring signals, tech stack changes

**Integrations**
- Native push to: HubSpot, Salesforce, Lemlist, Instantly, Smartlead, Outreach, Apollo Sequences
- HTTP API — push to anything
- CRM 2-way sync
- Clay Sequencer (built-in sending, basic — most power users still push to Lemlist/Instantly)

**Client Portal / User-facing**
- None — Clay is a data tool, not a client-facing product
- Shared workspaces for team collaboration

**Admin / Ops**
- Table-based view (like Airtable but for GTM data)
- Credit usage dashboard
- Run logs per workflow
- Template library (pre-built "recipes" for common use cases)

**Pricing (March 2026 update — big cuts)**
- Free: 100 Data Credits + 500 Actions/month
- Launch: $185/month — 2,500 credits + 15,000 actions
- Growth: $495/month — full waterfall, CRM, APIs, 40,000 actions
- Pro: $800/month (now largely replaced by Growth post price cuts)
- Clay cut costs 50–90% in March 2026

# WHERE WE WIN — UNCONTESTED GROUND

These are features **no competitor has** in combination:

1. **Done-for-you managed outbound** — Every competitor is a tool you run. We run it for you. This is the entire model.
2. **White-label client portal, purpose-built** — No one else has a clean client-facing portal. They all assume the user *is* the client.
3. **Credit model / pay per lead delivered** — Industry standard is per-seat-per-month regardless of results. We put skin in the game.
4. **African B2B market + POPIA** — Zero competitors have African focus, African data density, ZAR pricing, or POPIA handling.
5. **AI that runs the campaign (not assists)** — FIGSY is autonomous. Most AI in this space is a "write this email for me" button. FIGSY finds the lead, builds the sequence, sends it, pauses on reply, learns from results. That's a different category.
