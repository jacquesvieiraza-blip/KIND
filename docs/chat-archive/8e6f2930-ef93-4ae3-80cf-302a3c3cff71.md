## ClickUp Brain Agents — Deep Dive

---

### The Core Concept: What Makes Them Different

Most AI tools are **reactive** — you prompt, it responds, it stops. Brain Agents (Super Agents) break this by being **proactive and persistent**. The mental model ClickUp uses:

> *"If a traditional AI agent can run a quick data analysis, a Super Agent is the analyst — who gathers the data, runs the model, interprets the results, and delivers the report in the right format to the right stakeholder, without being explicitly told each step."*

They're not chatbots. They're not automations. They sit somewhere in between — goal-directed, reasoning continuously, working while you're offline.

---

### How They're Actually Built

ClickUp **acquired Codegen** (a Cursor competitor, Dec 2025) specifically to supercharge the Super Agent architecture. Three technical layers:

| Layer | What it does |
|---|---|
| **Reasoning / LLM core** | Multi-model (GPT-5, Claude Opus, o3) — decomposes goals into steps, drafts text, plans workflows |
| **Memory & retrieval** | Searchable vector indexes — agents recall past interactions, past decisions, workspace history |
| **Tool execution** | Can create tasks, send emails, update fields, post in chat, generate images, call integrations |

The reasoning loop is: **observe → decompose → select tools → execute → verify → escalate if uncertain**. The escalation part is key — instead of guessing or hallucinating forward, it stops and asks a human when context is insufficient.

---

### How You Set One Up

Three ways to create an agent:

1. **Natural language builder** — describe what you want in plain English, ClickUp configures it for you
2. **From scratch** — manual profile configuration
3. **Templates** — prebuilt agents for common roles (bug triage, standup, onboarding, etc.)

Each agent profile has 5 sections:

**1. Instructions** — the agent's personality, role, rules, and constraints. Written in plain text. E.g. "You are a client success agent. Always be concise. Never share pricing without approval."

**2. Triggers** — what wakes the agent up:
- `@mention` in a task comment, doc, or chat
- Direct message (it replies like a person in DMs)
- Being assigned a task (it starts working on it)
- Scheduled: hourly / daily / weekly / monthly / custom cron
- Automation-triggered: fired by a ClickUp rule (e.g. when status changes to "Review", ping the agent)

**3. Skills** — what it can do. 500+ prebuilt, including:
- Research & web search
- Summarisation
- Task creation and routing
- Email drafting and sending
- Image generation
- Meeting follow-up email generation
- Duplicate detection
- Missing info notification
- Assignment recommendations
