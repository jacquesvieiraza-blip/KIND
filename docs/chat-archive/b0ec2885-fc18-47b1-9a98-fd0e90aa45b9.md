### 1. API Bug Fixes — `.single()` → `.maybeSingle()` (commit `3cc893b`)

**Root cause:** Supabase `.single()` throws a hard error (PGRST116) when zero rows are returned. This means any null-check guard after the call (`if (!data)`) never runs — the handler crashes with a 500 instead of returning a clean "not found."

**Most critical fix — `getClientId` helpers.** Every single authenticated API endpoint calls `getClientId(userId)` first.
