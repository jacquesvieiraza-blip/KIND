   - Issue: No details on implementation; unclear if production-ready
   - Action: Review flutterwave.ts to ensure feature completeness.

### HIGH PRIORITY ISSUES

4. **Portal: ICP Prefill localStorage could collide**
   - Code: `localStorage.setItem('kind_icp_prefill', JSON.stringify(suggestions))`
   - Risk: If multiple clients use same browser, prefill data could bleed between accounts.
   - Action: Namespace localStorage keys with user ID or session ID.

5. **Portal: Billing page — missing Paystack integration check**
   - Code: Credit bundles only check Stripe (`stripeReady` = STRIPE_LEADGEN_BUNDLES.some(b => b.priceId))
   - Missing: Check for Paystack setup in bundle selection
   - Impact: Paystack price IDs may not exist; form will be disabled silently.
   - Action: Add Paystack price ID validation or clarify which payment method is primary.

6. **API: No rate limiting visible**
   - Issue: No apparent rate limiting on endpoints
   - Risk: Abuse, credit drain, expensive API calls (Apollo, Anthropic)
   - Action: Add rate limiting middleware (per IP, per user, per route).

7. **API: Email sending hardcoded to Resend without fallback**
   - File: `/lib/email.ts`
   - Risk: If Resend fails, no fallback provider; emails silent-fail
   - Action: Add logging and optional fallback (e.g., SendGrid, AWS SES).

### MEDIUM PRIORITY ISSUES

8. **Portal: Bulk operations in leads page lack confirmation dialogs**
   - Code: `bulkConsentSend()`, `bulkExport()`, `bulkMarkAs()`
   - Issue: User can accidentally bulk-action all selected leads without confirmation
   - Action: Add "Are you sure?" modal for irreversible bulk actions.

9. **Portal: Error handling inconsistencies**
   - Issue: Some error states show toasts, others show full-page errors
   - Impact: UX is inconsistent; silent failures possible
   - Action: Standardize error handling (all critical errors should be visible).

10. **API: Cron jobs call `http://localhost:${PORT}/internal`**
    - File: `/cron.ts`
    - Issue: Won't work if API is behind load balancer or in containerized environment
    - Action: Use direct function calls or internal endpoint that's not HTTP-based.

11. **Portal: No offline detection**
    - Issue: If API is unreachable, pages show generic "Failed to fetch" error
    - Action: Add offline banner, queue failed requests for retry.

12. **Admin Portal: Hardcoded PRICING/PRODUCTS references**
    - Issue: If these constants change in shared lib, admin dashboards won't auto-update pricing display
    - Action: Add "pricing last updated at" timestamp, cache invalidation.

### LOW PRIORITY ISSUES

13. **Portal: Floating AI chat panel on ICP page doesn't persist state**
    - Issue: Reloading page loses chat history
    - Action: Store chat in sessionStorage or backend.

14. **Website: Large video file (7.1MB) not optimized**
    - File: `platform-video-standalone.html`
    - Action: Compress, lazy-load, or move to CDN.

15. **TypeScript: Some `any` types in API**
