MCP (Model Context Protocol) is an open standard that lets AI models connect to external tools and data sources through a consistent interface.

## How it works

**The basic idea:** Instead of hardcoding integrations, you define a server that exposes "tools" — and any MCP-compatible client (Claude, Cursor, etc.) can call those tools.

```
AI Client  ←→  MCP Protocol  ←→  MCP Server  ←→  External System
(Claude)                          (your code)       (DB, API, etc.)
```

## Three core primitives

| Primitive | What it is | Example |
|-----------|-----------|---------|
| **Tools** | Functions the AI can call | `search_leads`, `send_email` |
| **Resources** | Data the AI can read | Files, DB rows, documents |
| **Prompts** | Reusable prompt templates | "Summarise this campaign" |

## A minimal MCP server

```typescript
import { Server } from '@modelcontextprotocol/sdk/server'

const server = new Server({ name: 'kind-mcp', version: '1.0' })

server.setRequestHandler('tools/list', async () => ({
  tools: [{
    name: 'get_leads',
    description: 'Fetch leads for a client',
    inputSchema: {
      type: 'object',
      properties: { client_id: { type: 'string' } },
      required: ['client_id'],
    },
  }]
}))

server.setRequestHandler('tools/call', async (req) => {
  if (req.params.name === 'get_leads') {
    const leads = await db.from('leads').select('*').eq('client_id', req.params.arguments.client_id)
    return { content: [{ type: 'text', text: JSON.stringify(leads) }] }
  }
})
```

## Transport options

- **stdio** — local process, Claude Code uses this (tools run as subprocesses)
- **HTTP/SSE** — remote server, accessible over the network (what KIND's MCP-1 uses)

## Discovery

Clients find your server via `/.well-known/mcp.json`:
```json
{
  "name": "KIND AI",
  "version": "1.0",
  "tools_endpoint": "/mcp/tools",
  "call_endpoint": "/mcp/call"
}
```

## In the context of KIND

- **MCP-1** (built): KIND exposes FIGSY's tools (`get_leads`, `create_campaign`, `get_kpis`) as an MCP server — so any external AI client can control KIND
- **MCP-2** (built): Milla's integrations panel shows external tools (Google Calendar, HubSpot, Slack) that will connect *into* Milla via MCP once credentials are added

The key insight is that MCP is just a standardised way of saying "here are the things an AI can do" — it replaces one-off API integrations with a single protocol.
