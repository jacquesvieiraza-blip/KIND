## The real concern — and it's legitimate

**Apollo's API is the dependency.** Three risks:

**1. Rate limits, not just credits**
Apollo throttles API calls. Running many client ICPs simultaneously could hit request-per-minute limits, not credit limits. You'd need to queue ICP runs rather than running them all at once. Not a blocker — just an architecture consideration when you have 20+ clients.

**2. Terms of Service**
Apollo's ToS restricts using their API to build a competing lead gen service or to resell their data. You're not selling Apollo data — you're selling a managed service that uses Apollo as one source. That's a meaningful distinction, but worth having a lawyer confirm before you're at scale.

**3. Apollo as a single point of failure**
If Apollo changes pricing, restricts API access, or goes down — your lead gen product stops working. Mitigation: build the ICP system to be data-source agnostic. Apollo today, plug in Hunter.io, Clearbit, or LinkedIn Sales Navigator as alternatives later.
